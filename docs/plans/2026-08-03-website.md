# Baimon (ใบหม่อน) — Website Final Plan

Date: 2026-08-03 · Phase 5 of 5 (final-plan) · Rev 12 (drawer portal fix)

## Feature

Thai-language money-splitting website **Baimon (ใบหม่อน)** (company: **Lomana Loma**)
with three calculators, Google AdSense ads in high-visibility in-content spots,
cookie-consent gating, optional discount input, per-page custom banner images,
image-based home tool cards, a privacy policy page, and the
"Aureus Premier" gold theme adapted to a light (white) background.

## Requirements recap

- Next.js App Router + TypeScript + Tailwind CSS, UI text in Thai, THB currency
  (`Intl.NumberFormat('th-TH', { style: 'currency', currency: 'THB' })`).
- 50/50 split labeled **คำนวณคนละครึ่ง**.
- Government co-payment calculator labeled **คำนวณไทยช่วยไทย 60/40** with a
  200 THB/day support cap. **Stateless**: every submit recalculates against the
  fixed 200 THB/day cap — no session/localStorage tracking, no reset button.
- Party split labeled **หารกัน**; satang remainder assigned to the first row.
- Optional discount (percent or baht) on all three calculators, applied to the
  total **before** splitting; the 60/40 cap applies to the discounted total.
- Cookie-consent banner; AdSense only loads after the user accepts.
- Google AdSense ads (client ID from `.env`) in popular in-content spots:
  top of page below the site header, above the calculator card (calculators),
  below the results block (calculators), and between hero and tool cards (home);
  all units in normal page flow (no fixed positioning on any screen).
- Custom banner image per calculator page from `public/images/`.
- Vitest + React Testing Library unit tests.
- Document title **Baimon (ใบหม่อน)**; company byline **Lomana Loma**.
- Privacy policy screen at `/privacy`, linked from the footer.
- Fonts served locally from `fonts/` (no Google-hosted text fonts).

## What was done

- **Scaffold**: Next.js 16.2.12 (Turbopack) app; Vitest 4 + RTL + jsdom;
  `npm run test` script.
- **Pure calc functions** (`src/calc/`, framework-free):
  - `round.ts` — `round2` (2-dp rounding).
  - `splitHalf.ts` — `splitHalf(total)` → `[half, total-half]`.
  - `splitThaiHelp.ts` — `splitThaiHelp(total, remaining)` with `THAI_HELP_DAILY_CAP = 200`;
    `govShare = min(round2(total*0.6), remaining)`, `userShare = total - govShare`.
  - `splitParty.ts` — `splitParty(total, people)`; satang remainder → first row.
  - `discount.ts` — `applyDiscount(total, type, value)` with `DiscountType =
    "percent" | "baht"`; percent clamped to ≤100.
- **Utilities**:
  - `src/lib/format.ts` — `formatBaht` THB formatter.
  - `src/lib/consent.ts` — `baimon_cookie_consent=accepted|declined` cookie
    (`Path=/; Max-Age=31536000; SameSite=Lax`), `readConsent`/`getConsent`/
    `writeConsent`/`subscribeConsent` (store-based).
- **Theme** (`src/app/globals.css`): Tailwind v4 `@theme` tokens — light palette
  (white `#ffffff` surfaces, warm light container grays, near-black
  `on-surface` `#1c1a17`, readable gold `primary` `#8a6a1f`, gold
  `primary-container` `#d4af37`) + utilities `.glass-card` (white/75% +
  gold-tinted border), `.label-caps`, `.calculate-btn-gradient` (gold shine),
  `.hero-gradient` (stronger glow on white); Material Symbols icons
  (Google-hosted, icon glyphs only). `themeColor: "#ffffff"` in metadata.
- **Banners**: `src/components/Banner.tsx` (client, `onError` fallback) renders
  `public/images/split-half.png` on /split-half, `public/images/thai-help.png`
  on /thai-help, `public/images/party.png` on /party (below the page header);
  missing/404 image shows a Thai placeholder telling the owner where to drop
  the file.
- **Fonts**: `next/font/google` replaced with `next/font/local` loading
  `fonts/NotoSansThai_Condensed-Regular.ttf` (Thai + Latin glyphs) as
  `--font-noto-thai`; `--font-headline`, `--font-body`, `--font-label` all map
  to it (single weight 400, bold via synthetic bolding).
- **Components** (`src/components/`):
  - `Nav.tsx` — sticky dark header, active-route highlight via `usePathname`.
  - `CookieConsent.tsx` — banner (ยอมรับทั้งหมด / ปฏิเสธ) driven by
    `useSyncExternalStore`; hides once decided.
  - `AdBanner.tsx` — single responsive `<ins>` per unit, always in page flow
    (`mx-auto mb-12 mt-6 w-full max-w-150`, `min-h-30` placeholder; no fixed
    positioning on any screen); `window.adsbygoogle.push` only after
    consent = `accepted` (localStorage fallback for the config check).
  - `Banner.tsx` — client banner with `onError` fallback for the per-page
    image (`public/images/{split-half,thai-help,party}.png`); missing/404
    image shows a Thai placeholder telling the owner where to drop the file.
  - `DiscountInput.tsx` — select (เปอร์เซ็นต์ (%) / บาท) + number input.
  - `MobileMenu.tsx` — mobile drawer (md+ hidden toggle button, slide-in right
    panel over a click-to-close backdrop): หน้าแรก / คนละครึ่ง / ไทยช่วยไทย /
    หารกัน / นโยบายความเป็นส่วนตัว, active-route highlight via `usePathname`,
    closes on link click, backdrop click, Esc, or close button; body scroll
    locked while open. Replaces the previously dead เมนู button in the header.
    The open drawer is rendered through `createPortal` into `document.body` so
    the header's `backdrop-filter` (which otherwise becomes the containing
    block for `position: fixed` descendants) and stacking context cannot trap
    or squash it behind `<main>`.
- **Pages** (`src/app/`):
  - `layout.tsx` — `lang="th"`, dark metadata theme, header + footer,
    consent-gated AdSense bootstrap `<script>`.
  - `page.tsx` — hero (baimon branding + **Lomana Loma** badge), 3 image-header
    tool cards, 2 ad slots (top + between hero and cards).
  - `split-half/page.tsx` — คำณวณคนละครึ่ง with discount.
  - `thai-help/page.tsx` — ไทยช่วยไทย 60/40, stateless, cap card
    (รัฐสนับสนุนสูงสุด ฿200.00 / วัน), discount; แทนที่สถานะของวันนี้ logic removed.
  - `party/page.tsx` — หารกัน N-way split with remainder on first row + discount.
  - `privacy/page.tsx` — นโยบายความเป็นส่วนตัว (Thai): in-browser calculation,
    `baimon_cookie_consent` cookie, Google AdSense + link to Google's privacy
    policy, user rights, contact `contact@lomanaloma.com`, back-to-home link;
    footer link wired to `/privacy`; document titles set to **Baimon (ใบหม่อน)**.
- **Ad slots** (each `AdBanner` unit carries a unique 10-digit placeholder slot):
  - Home: `0000000000` (top, below site header) + `4444444444` (between hero and tool cards).
  - split-half: `1111111111` (top) + `5555555555` (above calculator card) + `6666666666` (below results).
  - thai-help: `2222222222` (top) + `7777777777` (above calculator card) + `8888888888` (below results).
  - party: `3333333333` (top) + `9999999999` (above calculator card) + `1010101010` (below results).
  - Privacy page: no ads.
- **Home tool cards** (`src/app/page.tsx`): Material icon chips replaced with
  the three banner PNGs as full-width card headers (`aspect-video object-cover`,
  `loading="lazy"`, Thai `alt`), title/description below; hero badge keeps the
  Material icon.
- **Branding**: all "Fintech Solutions" bylines replaced with **Lomana Loma**
  (home hero badge, footer copyright).
- **AdSense**: client ID from `NEXT_PUBLIC_AD_CLIENT_ID` (`.env`, gitignored;
  `.env.example` committed via `!.env.example`) with fallback
  `ca-pub-XXXXXXXXXXXXXXXX` in `src/lib/config.ts`; used by `AdBanner.tsx`, the
  bootstrap `<script>` in `layout.tsx`, and the site-verification meta tag
  `<meta name="google-adsense-account" content="ca-pub-...">` (via the
  `other` field of `layout.tsx` metadata).
- **Types**: `src/types/adsbygoogle.d.ts` (optional `window.adsbygoogle`).
- **Config**: `vitest.config.mts`, `vitest.setup.ts` (jest-dom + RTL cleanup),
  `package.json` (`test` script).

## Test results

- `npm run test`: **63 passed, 0 failed, 0 skipped** (14 test files).
  - Calc: `round`, `splitHalf`, `splitThaiHelp` (cap/partial), `splitParty`
    (remainder→first row), `discount` (percent/baht/clamping/negatives).
  - Pages: home (hero heading, 3 card images with Thai alt + correct src,
    card links to each calculator), split-half (half split, odd satang, % and
    baht discounts), thai-help (60/40 + 200 cap, cap on discounted total,
    discount), party (N-way, single person, % and baht discounts), privacy
    (heading, cookie mention, Google privacy link, contact email, back link).
  - Components: `CookieConsent` (accept/decline writes cookie), `AdBanner`
    (ad pushed after consent, not before; in-flow classes, no `fixed` at any
    breakpoint), `Banner` (image renders with configured src; Thai placeholder
    on load error), `MobileMenu` (closed by default; opens with all 5 Thai
    links; closes on link, backdrop, and Esc).
- `npm run lint`: 0 errors, 1 expected warning
  (`@next/next/no-page-custom-font` — false positive for App Router layouts).
- `npm run build`: success, 8 static routes (`/`, `/_not-found`, `/party`,
  `/privacy`, `/split-half`, `/thai-help`).
- Manual smoke: `npm run start` → all routes plus the three banner images
  (`/images/{split-half,thai-help,party}.png`) return HTTP 200; rendered home
  HTML contains both ad slots and the card image paths; split-half HTML
  contains its three slots.
