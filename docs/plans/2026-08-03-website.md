# baimon (ใบหม่อน) — Website Final Plan

Date: 2026-08-03 · Phase 5 of 5 (final-plan)

## Feature

Thai-language money-splitting website **baimon (ใบหม่อน)** with three calculators
and Google AdSense support.

## Requirements recap

- Next.js App Router + TypeScript + Tailwind CSS, UI text in Thai, THB currency
  (`Intl.NumberFormat('th-TH', { style: 'currency', currency: 'THB' })`).
- 50/50 split labeled **คำนวณคนละครึ่ง**.
- Government co-payment calculator labeled **คำนวณไทยช่วยไทย 60/40** with a
  200 THB/day support cap, tracked across entries per calendar day.
- Party split labeled **หารกัน**; satang remainder assigned to the first row.
- Google AdSense banner below each calculator (placeholder publisher ID).
- Vitest + React Testing Library unit tests.

## What was done

- **Scaffold**: Next.js 16.2.12 (Turbopack) app created and moved into this repo;
  Vitest 4 + RTL + jsdom added; `npm run test` script added.
- **Pure calc functions** (`src/calc/`, framework-free):
  - `round.ts` — `round2` (2-dp rounding).
  - `splitHalf.ts` — `splitHalf(total)` → `[half, total-half]`.
  - `splitThaiHelp.ts` — `splitThaiHelp(total, remaining)` with `THAI_HELP_DAILY_CAP = 200`;
    `govShare = min(round2(total*0.6), remaining)`, `userShare = total - govShare`.
  - `splitParty.ts` — `splitParty(total, people)`; satang remainder → first row.
- **Utility**: `src/lib/format.ts` — `formatBaht` THB formatter.
- **Pages** (`src/app/`):
  - `layout.tsx` — `lang="th"`, metadata, header nav, footer, AdSense script tag.
  - `page.tsx` — home with 3 Thai nav cards + `AdBanner`.
  - `split-half/page.tsx` — คำณวณคนละครึ่ง client calculator.
  - `thai-help/page.tsx` — ไทยช่วยไทย 60/40 with daily budget via `useSyncExternalStore` + `localStorage` (resets each day, `รีเซ็ตสิทธิ์วันนี้` button).
  - `party/page.tsx` — หารกัน N-way split with remainder on first row.
- **AdSense**: `src/components/AdBanner.tsx` (responsive `<ins>` + guarded
  `window.adsbygoogle.push`), client placeholder `ca-pub-XXXXXXXXXXXXXXXX` in
  `layout.tsx` and `AdBanner.tsx` — swap in a real AdSense client ID to serve ads.
- **Types**: `src/types/adsbygoogle.d.ts` for `window.adsbygoogle`.
- **Config**: `vitest.config.mts`, `vitest.setup.ts` (jest-dom + RTL cleanup),
  `src/app` test files, `package.json` (`test` script).
